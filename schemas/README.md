# Authored schemas

Place hand-written JSON Schema draft 2020-12 files here when an authored specification requires machine validation. Link each schema from its owning specification and record its owner there.

No authored schemas exist yet. `bun run check` reports the number validated, including zero. See the [schema authoring rules](../CONTRIBUTING.md#author-a-json-schema).

Do not store generated OpenAPI or server event schemas here. Consume them from [bot contract releases](https://github.com/crumble-project/bot/releases).
